# NetDust
.nd to write, ndr to run a small scripting language.<br>
from entry point to architecture.

## Official Libraries
 + std/: The official standard library. It is stable with no major or breaking changes.
 + ntd/: The official extension library. It is unstable and undergoes frequent updates.

## Community Libraries
+ lib/: An assortment of third party libraries developed and distributed directly by users.

## Official Net Dust Engines
| Engine | Platform | Based |
| :--- | :---: | :--- |
| **Net Dust Runtime (ndr)** | macOS / Cross platform | C++/Objective-C |
| **Noctura** | Windows | C# .NET |

> [!WARNING]
>
> **NetDust is currently under active development, so its syntax may change and some features may not work as expected.**
